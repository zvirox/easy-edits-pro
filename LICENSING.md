# LICENSING.md

Easy Edits Pro is **dual licensed**. Pick the licence that matches your use case:

## 1. Open source — AGPL-3.0-or-later (the default)

Free for personal use, open-source projects, research, and anyone who shares
their source as required by the licence. See [LICENSE](LICENSE) for the full
text (GNU Affero General Public License v3, or any later version at your
option).

The AGPL's section 13 means that if you **run a modified version as a network
service** (for example a hosted EEP engine or MCP server), you must offer
your users the Corresponding Source of that version. If that obligation does
not fit your business, read section 2.

## 2. Commercial licence — for closed products and hosted services

For companies that want to embed Easy Edits Pro in a closed product, or run
it as a hosted service **without** the AGPL source-sharing obligation, and
for paid support/SLA arrangements. The commercial path is a separate signed
contract, not this file — see [LICENSE-COMMERCIAL.md](LICENSE-COMMERCIAL.md)
for how to request it.

## 3. How the two relate

- The repository ships under the AGPL-3.0-or-later terms by default.
- A commercial licence is a *separately signed agreement*; it never changes
  what past or present AGPL releases grant to the public.
- Third-party components keep their own licences (see
  [NOTICE](NOTICE) and `licenses/`); the commercial licence covers only the
  Easy Edits Pro code and its copyright holders. Codecs and patent licensing
  remain the customer's responsibility.
- Model weights are **not** bundled. Any future model must clear the gate in
  [docs/model-licences.md](docs/model-licences.md) first — non-commercial
  weights are never included without the maintainer's written approval.

## 4. Contributing

Contributors keep their copyright and sign the contributor licence agreement
in [CLA.md](CLA.md) so that the dual licence can be offered. The Developer
Certificate of Origin (DCO) sign-off in `CONTRIBUTING.md` still documents
origin; the CLA is what makes relicensing possible.
