# Getting help

| I want to... | Go to |
|---|---|
| Ask how something works, or share an idea | [GitHub Discussions](https://github.com/zvirox/easy-edits-pro/discussions) |
| Report a bug or request a feature | [Issues](https://github.com/zvirox/easy-edits-pro/issues/new/choose) (use the forms) |
| Report a security problem | [Private advisory](https://github.com/zvirox/easy-edits-pro/security/advisories/new) or **zvirox@proton.me**. See [SECURITY.md](SECURITY.md). Do not post publicly. |
| Ask about licences, the CLA, trademarks or commercial use | **info@zvirox.in** (alternative: **zvirox@proton.me**). See [LICENSING.md](LICENSING.md). |
| Report a Code of Conduct problem | **info@zvirox.in**. See [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md). |
| Contribute code or docs | [CONTRIBUTING.md](CONTRIBUTING.md) |

Easy Edits Pro is an alpha, maintained by a small team. We read everything but
cannot promise fixed response times; we aim to reply within about a week.

For a good bug report, include the version, your distribution and display
server, the steps to reproduce, and the output of **Help -> Copy System
Diagnostics**.
