## What's new since v0.1.0-alpha.2

### Glass cards UI overhaul, part 2 (plan v4 G5–G7)

- **All eight workspaces dock (G5):** media (Project Media import), audio
  (Fairlight Mixer / Master Bus / Track DSP / Automation tabs), deliver
  (Export tab), fusion (Fusion Canvas + Node Inspector tabs), and keyframes
  (Curves + Tangents tabs) now route through the same persistent shell as
  edit, color, and effects. The Fairlight picture-sync monitor and audio
  timeline tray retire — the shell program monitor and the persistent
  timeline own the picture and the tracks. The last clips reel tray
  (keyframes) is deleted; selection happens on the timeline.
- **Geometry invariance across every mode (G7):** the e2e invariance walk
  now covers all eight workspaces and proves the program monitor, toolbox,
  and timeline never move or remount when the mode changes.
- **Polish and bug fixes (G6):** the top menu bar sheds optional chrome
  progressively below 1400/1300px and scrolls in place below 1150px instead
  of painting over the right-side actions; every icon SVG gets a base
  stroked style (fixes the design-QA "empty squares" in Captions and
  Essential Graphics rows); the status bar is never obscured — asserted
  per workspace mode in e2e; dock cards mount with a 220ms fade+rise that
  respects `prefers-reduced-motion`.

## Package limitations (say this out loud)

- Packages are **known-buildable**, not known-installed: no install +
  launch result is recorded yet for any .deb/.rpm on any machine. Do not
  assume the package works before you record otherwise.
- Software H.264 is the only verified encoder path; hardware encoding is
  disabled-by-default and uncertified.
- Single laptop, single desktop environment development. Reports from other
  systems are feedback, not verified facts.
- Browser e2e tests mock the backend; they are UI-contract evidence, not
  engine or codec proof.

## Known gaps

- A large share of catalogue commands still report planned; the Fusion node
  graph actions and clip-gain/DSP edits intentionally return typed errors.
- Audio plugin slots are metadata-only until a tested native host exists;
  no VST3 hosting.
- Multicam and speech tools are placeholder surfaces.
- Project-file compatibility beyond this release's schema is best-effort;
  migrations run automatically and are fixture-tested up to the recorded
  versions.

## How to report

Attach: app version, install method, the app's diagnostics (Help →
Copy System Diagnostics), the affected area, the media codec involved, and
reproduction steps. See the bug-report template; triage details live in
[alpha-triage.md](../alpha-triage.md).
