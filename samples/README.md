# Sample projects

Two maintained `.saturn` bundles for new users, QA, and documentation
screenshots. They are generated by a script through the real engine - they are
not committed as artifacts, so they can never drift from the command set the
engine actually accepts.

| Bundle | Demonstrates |
|---|---|
| `First Cut.saturn` | Import, timeline clip split at the midpoint, In/Out marks, one marker, and a lower-third title ("First Cut") on a dedicated **Titles** video track overlaying the second half |
| `Captions and Colour.saturn` | Caption track with three timed cues, one marker, a per-clip colour grade (exposure 0.15 / contrast 1.1 / saturation 1.2), and a two-angle multicam group ("Sample two-angle") |

Every element in both bundles is built with shipped engine commands
(`project.add_media`, `timeline.add_clip`, `timeline.split_clip`,
`timeline.set_mark_in/out`, `marker.add`, `timeline.add_track`,
`timeline.add_title`, `caption.track_add`, `caption.cue_add`,
`clip.set_color`, `multicam.create`) through `saturn-cli control` - the same
dispatch the desktop editor uses.

## Regenerate

From the repository root:

```sh
# Build both bundles into a directory of your choice:
python3 tests/native/sample_projects.py --build DIR

# Rot-guard: fresh-build into a temp dir, assert the persisted structure
# (tracks, clips, marks, markers, title asset, caption cues, colour grade,
# multicam group), render First Cut through the real GStreamer pipeline,
# and verify the output with ffprobe:
python3 tests/native/sample_projects.py --verify
```

`--verify` builds `target/debug/saturn-cli` when missing; `ffprobe` and
GStreamer must be installed (same prerequisites as the native tests).

## Media provenance

All footage is repository-generated: FFmpeg `testsrc2` output re-encoded to
VP8 (see `apps/saturn-tauri/tests/fixtures/README.md` for the exact command).
No third-party footage is used or shipped. Each bundle carries its media under
`media/` (`footage.webm`, plus `angle-a.webm`/`angle-b.webm` for the multicam
sample).

## Known limitation: media paths are absolute

`.saturn` projects embed the absolute path of each media file (recorded at
import time). Moving a bundle directory (or opening it on another machine)
therefore shows its media offline until the clips are relinked to the media
files that travel inside the bundle. Buckets for fixing this (relative-path
storage or first-class relink-on-open) are already tracked elsewhere; the
samples do not paper over the limitation.

## Remaining E.2 tail

The packaging hookup - offering these samples on first run (or shipping them
inside the install package) - is deliberately not done yet. Regeneration and
the rot-guard above are the durable part of E.2; first-run wiring lands with
the Beta-1 packaging polish item and will need a command (or app-side
bootstrap) decision first.
