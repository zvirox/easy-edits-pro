# cli-anything-eep

Agent-native CLI for **Easy Edits Pro** — professional video editing on Linux.

Generated by [CLI-Anything](https://github.com/HKUDS/CLI-Anything) 7-phase pipeline.

## Installation

```bash
# From source (development)
cd agent-harness
pip install -e .

# Or from PyPI (when published)
pip install cli-anything-eep
```

## Usage

```bash
# Show help
cli-anything-eep --help

# Enter interactive REPL
cli-anything-eep

# Execute commands with JSON output (for agents)
cli-anything-eep --json project create --name "My Video" --template youtube-1080p
cli-anything-eep --json timeline create --name "Main" --fps 30
cli-anything-eep --json track add --kind video --name "V1"
cli-anything-eep --json clip add --source media.mp4 --track V1 --at 0
cli-anything-eep --json render queue --preset youtube --output out.mp4
```

## Command Groups

| Group | Description |
|-------|-------------|
| `project` | Project create/open/save/inspect |
| `timeline` | Timeline create/list/open/settings |
| `track` | Track add/remove/list/move/settings |
| `clip` | Clip add/move/trim/remove/speed/reverse |
| `render` | Render queue/status/cancel/presets |
| `template` | Template create/list/apply/export (.sgt) |
| `command` | Command registry list/execute/info |
| `daemon` | Control server start/stop/status |
| `mcp` | MCP server start/stop/tools/resources/prompts |
| `color` | Color grade/wheels/LUT/reset |
| `audio` | Audio mix/effect/meter/automation |
| `media` | Media import/search/list/bins/proxy/info |

## REPL Mode

```bash
cli-anything-eep
eep> project create --name "My Video"
eep> timeline create --name "Main" --fps 30
eep> track add --kind video --name "V1"
eep> clip add --source footage.mp4 --track V1 --at 0
eep> render queue --preset youtube --output out.mp4
eep> undo
eep> history
eep> exit
```

## Agent Integration

All commands support `--json` for structured output:

```bash
cli-anything-eep --json project create --name "Test" --template youtube-1080p
# {"success": true, "message": "Project 'Test' created", "data": {...}}
```

Errors are also structured:

```json
{
  "error": "BACKEND_NOT_FOUND",
  "message": "Required backend not found: saturn-cli",
  "details": {"backend": "saturn-cli"},
  "recoverable": false
}
```

## Backend Requirements

Requires **Easy Edits Pro** installed with `saturn-cli` on PATH:

```bash
# Build from source
cd /path/to/easy-edits-pro
cargo build --release --bin saturn-cli
export PATH=$PATH:/path/to/easy-edits-pro/target/release
```

Or install via your distribution's package manager.

## Architecture

This CLI wraps the Easy Edits Pro Rust crates:

| Crate | CLI Group |
|-------|-----------|
| `saturn-commands` | `command` |
| `saturn-timeline` | `timeline`, `track`, `clip` |
| `saturn-graphics` | `template` |
| `saturn-project` | `project`, `media` |
| `saturn-control` | `daemon` |
| `saturn-mcp` | `mcp` |
| `saturn-render` | `render` |
